# Kando Connect Corporate Website

Static corporate website for Kando Connect SRL.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- No external libraries
- GitHub Pages ready

## Languages
- English (default)
- Romanian
- Russian

## GitHub Pages
Open **Settings → Pages** and select:
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Expected public URL:
https://wertikooo-web.github.io/kando-connect/
